# Astronomy App Content Guidelines

These are the strict guidelines for writing celestial object content for the "Liquid Glass" bottom sheet UI. 
The target audience is absolute beginners.

## 1. The Vibe (Planet Personas)
- **Do not** write like a Wikipedia article.
- Treat each celestial object like a character at a party. 
- Give them a **"Persona" subtitle** (e.g., Venus is "The Hottest Planet in the Room", Jupiter is "The Heavyweight Champion with a Stormy Heart").

## 2. No Jargon
- You are **strictly forbidden** from using complex astronomical jargon.
- **Do not use terms like:** "Right Ascension", "Declination", "Spectral Class", "Kelvin", or "Astronomical Units".
- Keep language accessible and human-relatable.

## 3. Three Quick Stats
- Provide exactly **3 highly scannable, human-relatable stats**.
- Each stat must start with an **emoji**.
- *Example:* "⏱️ Light takes 43 mins to reach you"

## 4. The Body Text
- Provide exactly **two short paragraphs**.
- **Paragraph 1 (The Myth):** How did ancient humans view this object? What stories or cultural significance did it have?
- **Paragraph 2 (The Reality):** One mind-blowing, visceral fact about what it would feel like to actually be there. Focus on sensory details (temperature, gravity, atmosphere, visuals).
